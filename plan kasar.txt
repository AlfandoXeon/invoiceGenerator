ini adalah plan kasar saya untuk apliaksi ini kedepannya..
Nama aplikasi ini = Xeon Invoice Generator
Bahasa Aplikasi rencana = NodeJS ( hanya untuk lokal, tak akan di hosting )
Database = Gunakan Json atau sqlite 3 lokal ( di root folder saja ) untuk semua data nya


rencananya, saya mau menjual aplikasi ini kepada umkm umkm mini di daerah saya, untuk mempermudah mereka untuk mencetak invoice dari toko  mereka
masalahnya, mereka tidak memiliki biaya untuk hosting dan biaya teknis lainnya..
jadi maka dari itu, saya ingin membuat sebuah aplikasi server lokal, untuk toko toko umkm tersebut, agar bisa membuat invoice, dan mencetak nya, serta mengatur data data toko
hanya dengan satu kali run, node index.js saja

nanti semua konfigurasi, dari nama toko, logo toko, alamat, nomor telepon, dll, akan saya simpan dalam sebuah file json di root folder.. dan bisa di atur otomatis oleh owner umkm tersebut di dalam tampilan web lokal mereka
